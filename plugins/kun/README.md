# 养鲲 v4.0

> 开局一条鲲，进化全靠吞。

---

## 致敬原作者

玩法设计全部来自 **Agam** 的《简单的养鲲游戏》
（CQP 插件 `me.cqp.Agam.kun`，版本 1.19.9.4.1，2020 年）。

「开局一条鲲，进化全靠吞」、节操货币、砸蛋开道具、磨炼、幻化、拍卖行、
单挑群主、抽群主一个大嘴巴——**这些创意都不是我们的**，是 Agam 八年前就设计好的。

v4.0 是**按易语言源码 1:1 重写**：源码（IDE 导出的 `鲲.txt` / `鲲BOSS.txt` /
`常量数据表.txt`）逐行对照，每条回复文本、每个数值公式都从那里搬运，
连原版的怪癖也保留（攻击2 的 B 也用重A 算、渡劫失败进度条末尾缀个随机数字、
运势取 ID 前四位算……）。

原版是易语言编译的二进制，没法直接复用，这里是**按规则重写的 JS 实现**。
如果原作者认为有不妥，请联系删除。

## 怎么用

两种写法，随便挑一种：

```
@机器人 /kun 签到
*签到
```

- `@机器人 /kun <指令>` —— 群里推荐这个。官方机器人默认只收 @ 它的消息。
- `*<指令>` —— 原版写法。**需要机器人开通「全量消息」权限**才会收到没 @ 的群消息；
  没开通的话这条只在私聊生效。

`/kun 菜单` 和 `/kun BOSS菜单` 里每一条都是**可点击的**：点一下就把
`/kun <指令>` 填进输入框，不用自己敲。菜单显示的仍是原版文字（`*签到`），
点击插入的却是新写法。

私聊：`/kun 绑定 <群openid>` 之后，`/kun 磨炼 5`、`/kun 砸蛋 2`、`/kun 幻化`
就能操作绑定群里的鲲（对应原版的「（私）」指令）。

| `/kun 查询` | 看自己的鲲和家当 |

## 回复格式

回复走**官方 markdown 消息**：数字（体重/节操/蛋/奖励）和 `==标题==` 行加粗，
`@某人` 用官方 `<qqbot-at-user>` 标签，菜单项用 `<qqbot-cmd-input>` 做成可点击。
文本内容与原版逐字一致——加粗只是外面包 `**`，零宽字符只用来防止
`*` / `---` 被误解析，渲染出来一模一样。

markdown 发送失败会自动退回纯文本，内容不会丢。

## 平台差异与平替

原版跑在真实 QQ（酷Q + 真实 QQ 号）上，官方机器人有几处做不到，这里逐个处理：

| 原版（酷Q / 真实 QQ） | 本版（官方机器人） |
|---|---|
| `*命令` 前缀 | `@机器人 /kun 命令`，或 `*命令`（需全量消息权限） |
| `[CQ:at,qq=123]` | `<qqbot-at-user id="openid" />` |
| 真实 QQ 号 / 群号 | openid（官方不暴露 QQ 号） |
| 群成员列表遍历排行 | 遍历自己的存档（输出不变） |
| 名片→昵称→QQ号 | 存档昵称→openid |
| 运势按 QQ 前四位 | 「用户 + 日期」哈希取模（0~100，同一人同一天固定，每天变） |
| 置群员禁言 180 秒 | `ctx.api.muteMember`（平替保留） |
| 群流程里给受害者发私信 | **放弃**：群里已经 @ 通知过，私信是重复内容 |
| 查阅属性时私信一份 | **放弃**：群消息已有全文 |
| `_menuA` 弹信息框 | **放弃**：官方没有 GUI 弹窗 |
| `*绑定 群号`（可校验群成员） | `/kun 绑定 <群openid>`（存下来即可，官方查不了成员列表） |

## 测试

插件测试跟着插件走（框架仓库的 `.gitignore` 排除了 `plugins/`，不该依赖具体插件）：

```
node test/kun.mjs          # 49 条断言
node test/kun-play.mjs     # 整局通关，只打印过程供人眼检查
```

两个脚本都要框架里的测试夹具，默认找 `../../bot`，也可以用
`ROOST_FRAMEWORK=/path/to/qq-bot-roost` 指定。CI 会把框架 checkout 到
`.framework/` 再跑。

## 与原版的两处有意不同

1. **出售的「是否渡劫过」判定**：原版写 `取文本右边(鲲, 2) ≠ "★"`，取右边两个字符
   是「鲲★」，永远不等于单字符「★」——等于拍卖行永远不可用（原版笔误，显然想写 1）。
   本版按明显意图取右边 1 个字符。
2. **输出排行/排行榜的插入排序**：原版比较时用的是 `qcy[j]` 而不是 `d[j]`
   （原版 bug），本版用正确算法，输出格式不变。
