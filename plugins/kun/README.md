# 养鲲

> 开局一条鲲，进化全靠吞。

---

## 致敬原作者

这个插件的**玩法设计全部来自 Agam**。

| | |
|---|---|
| 原作 | 《简单的养鲲游戏》 |
| 作者 | **Agam** |
| 载体 | CQP 插件 `me.cqp.Agam.kun` |
| 版本 | 1.19.9.4.1 |
| 年代 | 2020 年 |

「开局一条鲲，进化全靠吞」这句 slogan、节操货币、砸蛋开道具、磨炼、
幻化、拍卖行、单挑群主、抽群主一个大嘴巴——**这些创意都不是我们的**，
是 Agam 在 2020 年就设计好的。

连数值也是从他的源码里读出来的，不是我们调的：

- 吞噬/攻击 25% 致命一击
- 发起吞噬/攻击 30% 获得一颗蛋
- 被吞噬后 75% 几率直接狗带
- 攻击/被攻击后 25% 恢复大量体重
- 磨炼 70% 概率不消耗节操
- 喂食/砸蛋 最多同时 100 颗
- 放生随机获得 2~10 颗蛋
- 砸蛋出道具概率 = 今日运势

**关于代码**：原版是易语言编译的二进制（`.e`），没法直接复用。
所以这里是**按原版规则重写的 JS 实现**，一行原版代码都没有。
如果原作者认为有不妥，请联系删除。

## 玩法

### 养成

| 命令 | 说明 |
|---|---|
| `/kun` 或群里说「我的鲲」 | 看自己的鲲 |
| `/签到` | 每日一次，赚节操和蛋，可能触发运势事件 |
| `/买蛋 [数量]` | 80 节操一颗 |
| `/砸蛋 [数量]` | 开蛋出道具，**概率取决于今日运势** |
| `/孵化` | 用一颗蛋孵出鲲，10% 概率出「悲」属性 |
| `/喂食 [数量]` | **消耗蛋**增重，一次最多 100 颗 |
| `/喝鸡汤 [数量]` | 回节操 |
| `/磨炼 [数值]` | 每天 30 次，70% 概率不消耗节操 |
| `/幻化` | 随机换品种，体重不变（悲属性不行） |

### 对抗

| 命令 | 说明 |
|---|---|
| `/吞噬 @某人` | 赢家抢对方 15% 体重，对方 75% 概率狗带 |
| `/渡劫` | 45% 体重翻倍，否则暴跌到一成 |
| `/单挑群主` | 赢了重赏，输了掉体重 |
| `/抽群主一个大嘴巴` | 白嫖节操 |

### 交易

| 命令 | 说明 |
|---|---|
| `/出售 [起拍价]` | 把自己的鲲挂到拍卖行 |
| `/出价 [竞拍价]` | 参与竞拍，必须高于当前价 |
| `/成交` | 卖家确认，鲲交给最高出价者 |
| `/下架` | 撤回来（满 5 分钟才可强制） |

### 活动与生存

| 命令 | 说明 |
|---|---|
| `/查询BOSS` | 看今日 BOSS 血量与阵亡名单 |
| `/攻击BOSS` | 按体重造成伤害，击杀奖励 300 节操 + 神器 |
| `/复活` | 用复活药救回阵亡的鲲 |
| `/放生` | 放弃当前鲲，随机获得 2~10 颗蛋 |
| `/鲲榜` | 体重排行前 5 |

|---|---|---|
| 普通 | 尘鲲 (´･ω･`) · 菜虚鲲 | 1.0 |
| 稀有 | 碧鲲 (◕‿◕) · 虹鲲 | 1.15 |
| 史诗 | 炎鲲 (╬￣皿￣) · 钢背鲲 | 1.35 |
| 传说 | 帝鲲 (｀・ω・´) · 骨鲲 (☠д☠) | 1.6 |

---

## 属性

每只鲲有 智 / 力 / 速 / 韧 四种属性之一。

孵化时 **10% 概率出「悲」属性**——悲属性的鲲**无法幻化、无法复活**，
是原版就有的负面设定。

---

## 数据

按玩家存：`data/bots/<机器人id>/plugins/kun.json`

全局状态：`__boss`（今日 BOSS）、`__auction`（拍卖行）

面板「插件 → 设置」里可以直接改配置和玩家数据。
