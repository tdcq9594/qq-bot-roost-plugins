# 禁漫下载（jm-comic）

在群里发一个禁漫 ID，机器人把整本下载下来、还原被竖着切乱打散的画面、合成一份 PDF，再作为群文件发回会话。

- 插件 id：`jm-comic`
- 版本：1.0.0
- 依赖：**只需要 ffmpeg**（用于还原画面与转码，市场安装时不会装任何 npm 包）

## 安装

**市场安装**：在「插件 → 插件市场」里找到「禁漫下载」，点安装。装完刷新插件页即可用，无需重启；
本插件不依赖任何 npm 包，市场不会下载依赖。

**手动安装**：把整个 `jm-comic` 目录放进 `roost/plugins/`（确保里面有 index.js），
刷新插件页或在面板里点「重新扫描」即可加载。

**唯一前置**：ffmpeg（见下面「需要 ffmpeg」）。没装也不会报错，只是发 ID 时会提示找不到 ffmpeg。
## 用法

在群里（或私聊）：

| 你发 | 它会 |
| --- | --- |
| `jm422444` / `JM-422444` / `禁漫 422444` | 下载 422444 这一本 |
| `https://18comic.vip/album/422444/xxx` | 同上（认链接里的 ID） |
| `@机器人 422444` | 同上（只 @ 时才认纯数字，避免误触发） |
| `/jm 422444` | 命令式下载 |
| `/jm` | 看当前状态（ffmpeg、并发、队列、今日统计） |
| `/jm 列表` | 看队列与本地已下载的书 |
| `/jm 暂停` / `/jm 继续` / `/jm 取消 <id>` / `/jm 删除 <id>` | 管理任务 |
| `/jm 开` / `/jm 关` / `/jm 群列表` / `/jm 全开` | 群白名单（管理员） |
| `/jm 清` | 清空本地成品（管理员） |

不 @ 也能触发，但必须带 `jm` / `禁漫` / `本子` 前缀，或者是个链接 —— 免得群里随便一个数字就开下载。

### 群白名单

默认所有群都能用。

- 在某个群发 `/jm 关`：这个群不再响应（名单为空时等于所有群都关？不，见下）。
- 更常用的是先 `@机器人 /jm 开` 把自己群加进白名单 —— **一旦名单里有群，就变成"只有名单里的群能用"**；`/jm 关` 把当前群移出名单，名单清空后自动恢复"所有群都能用"。
- 想一次放开：`/jm 全开`（清空名单）。

## 交付物

- 默认输出 **一份 PDF**（多章节会自动按顺序拼进同一个 PDF）。
- 可改成"输出图片"：把 `outputFormat` 设成 `images`，则把还原后的图片逐张发回（适合页数少的）。
- 成品会缓存 12 小时，同一个 ID 12 小时内再发直接重发文件，不重新下载。
- PDF 超过 `maxFileMB`（默认 90MB）时会自动降一档画质（质量 -25、最长边 1800）重压一次；还超就提示失败。

## 配置（面板：插件 → 禁漫下载）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | 开 | 总开关，关掉后命令也停 |
| `outputFormat` | `pdf` | `pdf` 或 `images` |
| `descramble` | 开 | 还原竖切打乱；关掉会得到拼错的图，只用于排查 |
| `pdfQuality` | 85 | PDF 内 JPEG 质量 |
| `pdfMaxDim` | 0 | 单页最长边（0=不缩） |
| `allChapters` | 开 | 多章节整本下载；关掉只下第一话 |
| `maxPages` | 500 | 单话最多下多少页 |
| `concurrency` | 4 | 同时下载几张图（太高容易被站点限速） |
| `timeoutSec` | 30 | 单次请求超时 |
| `uploadTarget` | `request` | `request`=发到当前会话 / `group`=群文件 / `private`=私聊 / `none`=只存本地 |
| `maxFileMB` | 90 | 单文件上限，超了自动降画质重压 |
| `keepDays` | 7 | 本地保留天数，过期自动清理 |
| `apiDomains` | 空 | 备用接口域名，逗号分隔，填了的排最前 |
| `proxy` | 空 | 下载代理，如 `http://127.0.0.1:7890`（可选能力：运行环境里有 `undici` 才生效，没有就直连并打一条日志） |
| `progress` | 开 | 群里报进度（每下完一话报一次，避免刷屏） |
| `ffmpegPath` | 空 | 一般不用填，会自动找；找不到就填 ffmpeg.exe 或它所在的 bin 目录 |

## 需要 ffmpeg

还原打散画面靠 ffmpeg 的 `crop` + `vstack`（把横带按正确顺序倒过来拼），转码成 JPEG 后直接塞进 PDF（`/DCTDecode`），所以不需要任何图像库。

自动查找顺序：配置里的路径 → PATH → `C:/ffmpeg/bin`、`D:/ffmpeg/bin`、`E:/ffmpeg/bin`、`C:/Program Files/ffmpeg/bin` 等常见位置。找不到的命令会回一句提示，插件本身不会崩。

Windows 装法：去 <https://www.gyan.dev/ffmpeg/builds/> 下 `ffmpeg-release-full.7z`，解压后把 `bin` 目录（含 `ffmpeg.exe`）放到 `C:/ffmpeg/bin`，不用装、不用改环境变量，重进面板即可。

## 原理备注

- 站点接口走 App UA 签名（`md5(ts+secret)` + `tokenparam`），响应是 `AES-256-ECB` 加密的 base64，解出来再 `JSON.parse`。桌面 UA 会直接被判 `Not legal request`。
- 画面被打散成 N 条横带并倒序拼接，`N` 由 `scramble_id`、本子 ID、文件名共同决定（`md5(本子ID+去扩展名的文件名)` 的末位），所以**同一个本子不同页的切块数可能不同**，必须逐页算。
- 图片直链必须带 `?v=<ts>`，否则拿到空数据。

## 数据与日志

- 本地文件：`data/bots/<bot>/plugins/jm-comic/jm-<ID>/`（原图 + 成品 PDF）
- 缓存与任务状态：同目录下的 `tasks.json`（重启后仍在）
- 日志：`logs/bots/<bot>/plugins/jm-comic.log`

## 许可

- 插件代码：永久免费，禁止收费转售与商业分发。
- 插件本身不内嵌、不分发任何漫画内容；它只是把用户自己请求的那一本从站点取回来、还原、合成本地文件。
- 图源是第三方站点，可用性、内容合法性由各站点负责；请遵守你所在地区的法律与站点条款。
- 插件不绕过站点的付费/权限机制：下载不到的内容照样下载不到。
