# 二次元图

> 来张图，别问，问就是二次元。

---

## 干什么

`/来张图` 发一张二次元图片到群里，**图片和出处文字是同一条消息**
（msg_type=7 富媒体消息自带的文本字段，不是先发图再补一句话）。

图源是[夜轻 ACG API](https://www.yeqing.net/blog/acg-api/)（`api.yppp.net`），
国内腾讯云 CDN，不需要 key。v1 用的是 Lolicon，已弃用。

四条设计取舍：

| 做法 | 为什么 |
|---|---|
| **夜轻图源**：`pc` 横图 / `pe` 竖图，`?return=json` 拿元数据 | 国内直连、免 key、返回 JSON（URL/宽/高/扩展名），不用抓 HTML |
| **本地缓存**：拉到的图存到插件目录 | 图源单张要几秒；官方接口上传本地文件比让它去拉远程 URL 稳 |
| **LRU 回收**：上限 200 张 | 缓存不能无限长，超了先删最久没发过的 |
| **按文件名去重**：缓存 id 取图片 URL 的文件名主干 | 夜轻官方「懒得做去重」，同一张图会反复出现；去重 + 发送次数轮转双管齐下 |

图片来源为互联网收集（QQ 群、壁纸网站等），可能包含 AIGC 作品，
**API 未提供内容分级参数**。请遵守原站规定，别拿去做商业用途。

## 指令

| 指令 | 说明 |
|---|---|
| `/来张图` | 随机来一张（缓存空了会现拉，可能要等几秒） |
| `/二次元`、`/acg` | 同上 |
| `/图库` | 缓存里有多少张、占多大、横竖各多少、最早/最新是什么时候 |
| `/清图库` | 清空缓存（管理员） |

## 配置

面板「插件 → 二次元图 → 设置」：

| 项 | 默认 | 说明 |
|---|---|---|
| `type` | `random` | 图类型：`pc` 横图 / `pe` 竖图 / `random` 随机横竖 |
| `maxFiles` | `200` | 缓存上限（张） |
| `minPool` | `5` | 缓存少于这个数就在后台补货 |
| `timeoutMs` | `25000` | 单次拉取超时 |

> 为什么不提供「自适应」`/api` 端点：它按 User-Agent 判断跳横图还是竖图，
> 机器人侧的 UA 不是移动端，调它永远落到 `pc`，还多一次 302。
> 要竖图就把 `type` 设成 `pe`。

## 图源注意事项

- **限流**：官方规定 10 秒内超过 20 次请求会触发 30 秒速率限制。
  插件内置滑窗，攒到 18 次就排队等，不踩线。
- **不去重**：官方明说「懒得做去重」。插件按 URL 文件名去重，
  且补货循环连续拿到重复图会收手（不会死循环卡住启动）。
- **无 SLA**：官方不保证可用性，海外调用可能失败。图源挂了插件会
  明确回复「图源没响应」，不会静默。
- 图床域名是 `list.yppp.net`（EdgeOne CDN），和 API 域名不是同一个。

## 数据

```
data/bots/<机器人>/plugins/anime-img/
├── imgcache/          # 图片本体，文件名 <URL文件名主干>.<ext>
└── index.json         # 缓存索引：id / 横竖 / 宽高 / 大小 / 收录时间 / 发送次数
```

`index.json` 里记了「发送次数」，挑图时优先发次数最少的——保证轮转，
不会一直发同一张。
