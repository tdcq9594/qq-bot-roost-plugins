# 二次元图

> 来张图，别问，问就是二次元。

---

## 干什么

`/来张图` 发一张二次元插画到群里，带出处（标题 / 画师 / pixiv id）。

三条设计取舍：

| 做法 | 为什么 |
|---|---|
| **国内图源**：Lolicon API（`api.lolicon.app`） | 国内能直连，返回 JSON 带标题/画师/尺寸/pid，不用抓 HTML |
| **本地缓存**：拉到的图存到插件目录 | 图源单张要十几秒；官方接口上传本地文件比让它去拉远程 URL 稳 |
| **LRU 回收**：上限 200 张 | 缓存不能无限长，超了先删最久没发过的 |

图都是 pixiv 上 `r18=false` 的作品。请遵守原站规定，别拿去做商业用途。

---

## 指令

| 指令 | 说明 |
|---|---|
| `/来张图` | 随机来一张（缓存空了会现拉，可能要等十几秒） |
| `/二次元`、`/acg` | 同上 |
| `/图库` | 缓存里有多少张、占多大、最早/最新是什么时候 |
| `/清图库` | 清空缓存（管理员） |

---

## 配置

面板「插件 → 二次元图 → 设置」：

| 项 | 默认 | 说明 |
|---|---|---|
| `source` | `lolicon` | 图源，目前只实现 lolicon |
| `maxFiles` | `200` | 缓存上限（张） |
| `minPool` | `5` | 缓存少于这个数就在后台补货 |
| `timeoutMs` | `25000` | 单次拉取超时 |

---

## 数据

```
data/bots/<机器人>/plugins/anime-img/
├── imgcache/          # 图片本体，文件名 <pid>_<p>.<ext>
└── index.json         # 缓存索引：pid / 标题 / 画师 / 尺寸 / 大小 / 收录时间 / 发送次数
```

`index.json` 里记了「发送次数」，挑图时优先发次数最少的——保证轮转，
不会一直发同一张。

## 依赖

只用 Node 内置的 `fetch`（Node 18+ 自带），没有第三方包。
