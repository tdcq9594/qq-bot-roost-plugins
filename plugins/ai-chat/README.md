# AI 对话

把大模型接进 QQ。**不需要任何指令**——它就在群里待着，自己判断该不该接话。

> v3 从头重写。跟 1.x 的区别：1.x 要 `@机器人 /ai 问题`，3.x 直接说话就行。

---

## 它怎么工作

```
群里每条消息
   ↓
① 规则门（不花钱）        冷却 / 每分钟配额 / 忽略词 / 别的插件的指令 → 挡掉大部分
   ↓
② 模型判断（一次调用）    不该接就输出 <skip>，一声不吭
   ↓
③ 说话                    该接才接，切段、引用、markdown 都处理好
```

**为什么不会吵**：三层都在起作用。默认回过一次会安静 20 秒，每分钟最多主动接 3 条；
被 @ 时不受这两个限制（那是在叫你）。

**别的插件的指令为什么不用管**：内核在分派阶段就把 `/xxx` 交给对应插件并 `return` 了，
插件监听器根本收不到。这是框架保证的，不是我们算的。

## 快速开始

### 1. 打开「接收所有消息」

机器人要能看见群里**所有**消息（不只是 @ 它的），得在
[QQ 开放平台](https://q.qq.com) → 你的机器人 → 开发设置里打开「**接收所有消息**」。
不开的话只有 @ 它的消息能进来，`AI 自己判断` 就退化成「只在被 @ 时说话」了。

### 2. 填 API Key

面板「插件 → AI 对话 → 设置」，只填两项：

| 字段 | 填什么 |
|---|---|
| `API 密钥` | `sk-` 开头，DeepSeek 在 platform.deepseek.com 申请 |
| `接口地址` | 默认就是 DeepSeek，不用改 |

不想手输？点面板顶部的**快速填入**：DeepSeek / Kimi / 通义 / 智谱 / 硅基流动 / 本地 Ollama 一键填好。

### 3. 在群里说话

```
今天好热啊
```

不用 @，不用 `/ai`。它觉得该接就接，不该接就看着。

## 配置

### 什么时候接话

| 字段 | 默认 | 说明 |
|---|---|---|
| `什么时候接话` | AI 自己判断 | 另一个选项是「只在被 @ 时说话」，最省 token |
| `接话冷却（秒）` | 20 | 回过一次后安静这么久 |
| `每分钟最多接几条` | 3 | 0 = 不限。被 @ 时不受限制 |
| `忽略这些开头` | `["/"]` | 第二道保险，防别的插件把前缀改了 |

### 人设

| 字段 | 说明 |
|---|---|
| `人设` | 全局系统提示词 |
| `群聊追加人设` / `私聊追加人设` | 按场景叠加 |

**按群单独设人设**：不用改配置——直接跟它说「以后在这个群里你是个毒舌群友」，
它会自己记下来（见下）。

### 记忆

**也没有指令。** 直接说：

| 你说 | 它做 |
|---|---|
| 「记住我住在杭州」 | 这个会话以后都记得 |
| 「忘掉杭州那条」 | 删掉相关记忆 |
| 「以后在这个群里你是个毒舌群友」 | 改这个会话的人设 |
| 「我们重新开始吧」 | 清空这个会话的上下文 |

实现方式是模型在回复里带 `<<remember: 内容>>` 这类标记，插件解析执行后把标记摘掉。
用户看到的还是正常的一句话。

### 接哪个 AI

`适配器` 决定「这一轮交给谁去想」：

| 适配器 | 接谁 | 要额外装什么 |
|---|---|---|
| `openai`（默认） | DeepSeek / Kimi / 通义 / 智谱 / 硅基流动 / Ollama / vLLM / one-api… | 什么都不用 |
| `dsh` | DeepSeek Harness | 装 [dsh-roost](https://github.com/tdcq9594/dsh-roost) |
| `webhook` | 任何能收 HTTP 的自建服务 | 无 |

`dsh` 和 `webhook` 走同一份**宿主协议**，写一个新宿主只要实现两端（收 `inbound`、回 `reply`）。
详见 [AI宿主插件方案](../docs/AI宿主插件方案.md)。

## 它能发什么

不只是文字。模型可以用动作标记让它发图、发语音：

| 标记 | 效果 |
|---|---|
| `<<image: 网址或路径>>` | 发一张图（**表情包、AI 画的图都走这条**） |
| `<<voice: 网址或路径>>` | 发一条语音 |

所以接上 DSH 之后，「发表情包」「画张图发群里」都是通的：
DSH 的 AI 有文件工具，能自己找表情包、能调生图工具画一张，
然后把路径塞进 `<<image: ...>>`。

一次最多发 3 个；扩展名有白名单（图片 png/jpg/gif/webp，语音 silk/amr/mp3/wav/ogg/m4a），
免得模型把别的文件当图发出去。

## 它能看见什么

官方接口给的东西全都用上了，不是只读一段文本：

| 消息类型 | 它看到 |
|---|---|
| 语音 | **官方 ASR 转好的文字**（不用自己识别） |
| 图片 | 图片地址 |
| 引用 | 被引用的原文 |
| 合并转发 | 官方展开后的聊天记录 |
| 卡片（B站/小程序） | 卡片标题与链接 |

## 和别的插件一起用

- **不占任何指令**，不会跟 `/kun`、`/签到` 之类冲突
- 群聊里被别的插件回复过的消息，它可能也会接一句（框架会把多个插件的回复
  合并成一条，带【插件名】标题，不会混在一起）
- 不想让它在某个群说话：面板「插件 → 分群开关」里关掉就行

## 常见问题

**它一句话都不说**
1. 开放平台没开「接收所有消息」→ 只有 @ 才进得来
2. 没填 API Key（此时只有 @ 它才会提醒你）
3. 冷却中 / 每分钟配额满了 → 开「调试日志」，日志里会写每条为什么没接

**它话太多**
把「什么时候接话」改成「只在被 @ 时说话」，或者调大冷却、调小每分钟上限。

**想让它在这个群换个性格**
直接说「以后在这个群里你是个……」；想看现在是什么，问它「你还记得什么」。
