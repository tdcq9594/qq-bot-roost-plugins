# 本地绘图 (ComfyUI)

群里发 `ai绘图+内容`，机器人就用**你自己电脑上的 ComfyUI** 画出来，并把图直接发到会话里。不联网、不耗 API 额度、不花一分钱。

---

## 它和「调云端接口」的区别

| | 本插件 | 云端绘图接口 |
|---|---|---|
| 出图在哪算 | 你的显卡 | 别人家的服务器 |
| 费用 | 0 | 按张计费 |
| 模型 | 你想用哪个就用哪个（本地权重） | 平台提供的 |
| 需要 | ComfyUI 装好、显卡够 | 一个 key |
| 队伍 | 只有你自己排队 | 全网排队 |

代价也很直接：**画图的时候显卡在忙**。群友连发十条，只有一条一条画。

---

## 前置条件（只做一次）

1. **装 ComfyUI**。推荐 [Comfy Desktop](https://www.comfy.org/download)（装完就是能用的状态）；也可以自己部署一份 ComfyUI。
2. **至少放一个绘图模型**。把 checkpoint 丢进 ComfyUI 的 `models/checkpoints`（或 `models/unet` / `diffusion_models`）。没有模型的话插件帮不了你 —— 它只是把请求交给 ComfyUI。
3. 别的都不用了：ComfyUI 装在哪个盘、用的哪个端口、出图存到哪，插件自己从 Comfy Desktop 的配置文件里读；连 Python 解释器都自动找。

**ComfyUI 没在运行也不用管** —— 有人第一次画图时，插件会在后台把它拉起来（第一次约 10~30 秒，之后复用）。

## 用法

### 群里直接说

```
ai绘图+一只猫坐在窗台上，午后阳光
```

- 关键词默认是 `ai绘图`，可以换成别的（面板里改）。
- 关键词后面就是需求，`+`、`：`、空格、逗号都行：`ai绘图：一只猫`、`ai绘图 一只猫` 一样能认。
- 想要竖图 / 横图，在末尾写尺寸就行：
  ```
  ai绘图+樱花树下的少女 832x1216
  ```
- 一句话可以画多张：面板里把「一次画几张」调到 2（默认 1，多张会明显变慢）。

不需要 @ 机器人。想只让 @ 时才触发，把关键词写得很长很怪就行（比如 `我的机器人快来画图`）。

### 命令

| 命令 | 作用 |
|---|---|
| `/绘图` | 看状态：模型、ComfyUI 地址与版本、程序目录、出图目录、累计次数 |
| `/绘图 模型` | 列出 ComfyUI 里现成的模型名 —— **填面板时照抄这行** |
| `/绘图 测试` | 用固定提示词画一张，验证链路（管理员） |
| `/绘图 清` | 清理插件自己生成的旧图、重置路径缓存（管理员） |

`/绘图 测试` 是最快的自检方式：新装完先跑一次，通了再交给群友。

## 设置项（面板 → 插件 → 本地绘图）

一共 29 项，**只需要填一个：模型文件名**。其余留空即自动。

### 必填

| 设置 | 说明 |
|---|---|
| 模型文件名 | ComfyUI 里显示的完整名字，**要带扩展名**，如 `waiIllustriousSDXL_v170.safetensors`。不知道叫什么就发 `/绘图 模型`，或故意填错一次 —— 报错里会把现有模型名全列出来 |

### 拆分模型才要填（单文件 checkpoint 请全部留空）

| 设置 | 说明 |
|---|---|
| 文本编码器 | `models/text_encoders` 里的文件名，如 `qwen_3_06b_base.safetensors` |
| 第二个文本编码器 | FLUX / SD3 / SDXL 这类双编码器模型才填，填了自动换用双编码器节点 |
| CLIP 类型 | Qwen-Image 系用 `stable_diffusion`，SD3 用 `sd3`，FLUX 用 `flux`，Wan 用 `wan`，SDXL 用 `sdxl` |
| VAE | `models/vae` 里的文件名，如 `qwen_image_vae.safetensors` |

> 怎么知道自己的模型是不是拆分模型？把模型名填进面板，插件会去问 ComfyUI 这个文件出现在哪个加载器的候选列表里 —— 出现在 `CheckpointLoaderSimple` 就是单文件，出现在 `UNETLoader` 就是拆分的。填错了它会直接告诉你缺什么。

### 连接与启动

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用绘图 | 开 | 总开关；关掉后关键词不触发，`/绘图` 也只回一句「已关闭」 |
| 触发关键词 | `ai绘图` | 多个用逗号分隔 |
| ComfyUI 地址 | 空 | 留空自动探本机 8188~8199；也可写死 `http://127.0.0.1:8188`。支持 `https://` 和远程主机 —— 填了就**直接探测这个地址本身**（不再拿它的端口去问本机） |
| 自动拉起 ComfyUI | 开 | 检测不到就在后台静默启动（`--port 8188 --listen 127.0.0.1 --disable-auto-launch`，无窗口，只监听本机）。拉起失败后 30 秒内不重试，避免连点几下攒出一堆半死进程 |
| ComfyUI 程序目录 | 空 | 含 `main.py` 的目录，自动从 Comfy Desktop 配置里找 |
| Python 解释器 | 空 | 自动找 `.venv` / `standalone-env` 里的那份 |
| 出图目录 | 空 | 自动读 Comfy Desktop 的设置；提示「出图文件不在了」时才手动指 |
| 等待启动超时 | 150000 | 自动拉起后最多等这么久；进程若中途退出会**立刻报错并附日志尾部**，不用等满 |

### 出图参数

| 设置 | 默认 | 说明 |
|---|---|---|
| 默认出图尺寸 | 空（按架构自动） | 单文件模型 1024x1024，拆分模型 832x1216（宽高都是 8 的倍数） |
| 采样步数 | 0（自动 30） | 20~50 较常见 |
| CFG | 0（自动） | 单文件 7.5，拆分 4 |
| 采样器 | auto | 单文件 `dpmpp_2m`，拆分 `euler` |
| 调度器 | auto | 单文件 `karras`，拆分 `sgm_uniform` |
| 默认负向提示词 | 一串压制模糊/水印的词 | 每张都会用 |
| 自动补质量标签 | 开 | 提示词里没有质量词时自动补 `masterpiece, best quality` |
| 画图时先打声招呼 | 开 | 动手前**立刻**发出「🎨 画着，稍等」（走 `replyNow`，不攒批）；队列有货时说「前面还有 N 张」 |
| 图上带一句尺寸说明 | 开 | 图配「🎨 832×1216」一起发。纯图消息正文为空，更容易被官方接口判违规 |
| 安全出图（压擦边） | 开 | 自动往负向词里加 `nsfw, nude, nipples, explicit, sex, lingerie, cleavage, panties, see-through` |

### 节奏与文件

| 设置 | 默认 | 说明 |
|---|---|---|
| 一次画几张 | 1 | 上限 4，多张明显变慢 |
| 同一会话冷却 | 20 秒 | 防刷屏 |
| 单张出图超时 | 180000 | 首次加载模型比之后慢很多，慢机器可调大。但官方群聊被动回复窗口只有 5 分钟（= 启动最长 150 秒 + 排队 + 出图 + 发送），默认压到 3 分钟；调过 5 分钟那张图很可能发不出去 |
| 图片体积上限 | 8 MB | 超过不发，避免协议端出问题 |
| 文件名前缀 | `roost` | 插件生成的图用这个前缀命名。**至少 3 个字符**、不能含 `\ / :` —— 太短会撞上别人的图，带斜杠会写进子目录导致清不掉；不合法时清理会自动跳过并记日志 |
| 保留旧图数量 | 200 | 超出后删最旧的、**本进程产出过**的图（按记录，不靠文件名猜），不碰你手动画的 |

## 它会自动找这些位置

装了 Comfy Desktop 就基本不用管：

1. `%APPDATA%\Comfy Desktop\settings.json` → 出图目录、输入目录
2. `%APPDATA%\Comfy Desktop\installations.json` → 实例的安装路径
3. `<安装路径>\ComfyUI\main.py` → 主程序
4. `<安装路径>\ComfyUI\.venv\Scripts\python.exe` 或 `<安装路径>\standalone-env\python.exe` → 解释器
5. `%APPDATA%\Comfy Desktop\instance-model-paths\*.yaml` → 额外的模型目录（`--extra-model-paths-config`）

任何一步找不到，`/绘图` 会明确告诉你卡在哪一步，而不是让你猜。

## 常见问题

**「ComfyUI 里找不到模型 xxx」**
模型名要**连扩展名一起**复制，且必须在 ComfyUI 的模型目录里（`models/checkpoints` 或 `models/unet`）。发 `/绘图 模型` 看现成的名字。

**「这是拆分模型，还需要填文本编码器和 VAE」**
你填的是 `models/unet` 里的扩散模型，不是打包好的 checkpoint。要么换成 `models/checkpoints` 里的单文件模型，要么按上面「拆分模型才要填」补齐四项。

**画得很慢**
第一次要加载模型（几十秒），之后快。看 `/绘图` 里的「累计」和队列提示；同一台机器同时只画一张，多张是排队不是并行。

**「出图文件不在了」**
图画出来了但插件去取的时候没找到 —— 通常是 Comfy Desktop 换了输出目录。看 `/绘图` 打印的「出图目录」，与 Comfy Desktop 设置里的对照；不一致就在面板「出图目录」手填。

**「连不上 ComfyUI」**
自动拉起失败了。手动打开 Comfy Desktop 看它自己报什么错（多半是自定义节点崩了，或显存不够）。起来了之后插件会直接复用，不会重复启动。

**显存不够 / 出黑图**
尺寸调小（`832x1216` → `1024x1024`），步数降到 20，一次只画 1 张。新式大模型对显存很敏感。

**图画出来了，群里却没看到图 / 提示「一张都没能发出去」**
框架发送富媒体失败时只记日志、不抛错（`replyImage` 返回 `null`），所以插件只能按现象给原因。按这个顺序排查：

1. **被动回复窗口过期**：官方只允许在收到消息后 5 分钟内被动回复，超了就得走主动额度。提示里会直接写「窗口已过期」或「窗口只剩 N 秒」—— 这种重画没用，让群友重新发一次触发词最快。
2. **主动额度用完 / 被限流**：同一会话每天/每分钟都有上限，提示里会写明。等一会儿再试，或看 `logs` 里 `message` 的报错码。
3. **内容审核判违规**：确认面板「安全出图」开着（默认开，会往负向词里加 `nsfw / nude / 露点` 一类词）；描述写稳一点，别只丢一个角色名 —— 本地模型对「角色名 + 没别的信息」很容易补成擦边构图，写成 `白洲梓, 1girl, blue archive, school uniform, indoors, looking at viewer` 这种更稳；仍被拦就换模型。
4. 想彻底不看审核脸色，就把输出当文件发（图就在本机目录里，自己取），或只在自己能看的地方用。

不管哪种，**图都已经落在本机出图目录里**，不会白画。

**「自动拉起的 ComfyUI 启动后立刻退出了」**
这不是插件猜的：它会盯着子进程的退出事件，一退就立刻停下等待，并把 `ComfyUI/user/comfyui.log` 的最后几行贴出来。常见原因是显存不够、自定义节点不兼容、或模型文件损坏。修好后 30 秒内不会再自动重试（避免攒出一堆半死进程）。

**提示「出图路径越界，已拒绝读取」**
ComfyUI 返回的文件名/子目录里带了 `..` 或绝对路径，插件拒绝按它读本地文件 —— 这是防护，不是故障。正常出图不会触发；若 `ComfyUI 地址` 填的是别人的远程服务，这条尤其重要（对方可以伪造返回值）。换回本机地址即可。

**图里出现奇怪的手指**
模型本身的毛病，不是插件。换模型、加负向词（`bad hands, extra fingers`）、或干脆避开手部特写。

## 数据与日志

| 位置 | 内容 |
|---|---|
| `data/bots/<bot>/plugins/comfy-draw/` | 本插件没用到（图都在 ComfyUI 的输出目录） |
| `logs/bots/<bot>/plugins/comfy-draw.log` | 启动、提交、出图、失败原因、清理记录 |
| ComfyUI 的 `user\comfyui.log` | ComfyUI 自己的日志（自动拉起失败时插件会贴出尾部） |
| 面板「本地绘图」卡片 | 出图次数、发出图片、失败、正在画、最近用时、当前模型 |

清理规则：只删**本进程产出过**的图（内存里记着绝对路径），并额外要求文件名前缀匹配；前缀不足 3 个字符或含路径符号时直接跳过清理并记一条日志。超时被中断的任务会先从 ComfyUI 队列里删掉（`POST /queue` 带 `delete`），不会留下一条之后自己跑起来、白占显存又没人取的任务（`/interrupt` 本身是全局的，共享 ComfyUI 上可能连带打断别人的任务，这是接口限制）。

开发自检：`node --test plugins/comfy-draw/test/` 跑纯函数与工作流图断言（不需要 ComfyUI、不连 QQ）。
