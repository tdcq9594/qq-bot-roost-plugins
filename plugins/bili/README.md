# 刷 B 站（bili）

给机器人一双**能看 B 站的眼睛**：别人发链接时它能点进去看标题、简介、字幕和热评；你说「刷点 B站」它会换一批热门给你聊。

标准 MCP server，stdio，**零依赖**（只要 Node ≥ 20），一个扩展 5 个工具，全部**只读**。

> 这不是 `dsh-bili-scroll` 那种「每天替你刷一轮、写日报、发评论」的插件。
> 那个要长期后台跑、要动你的账号；这个只在有人说话时被调用，看完就完事。
> 想自动刷 + 发评论，那是框架插件该干的事（那边才有「主人开口」的判定）。

## 工具

| 工具 | 什么时候用 | 入参 |
|---|---|---|
| `hot` | 「刷点 B站」「有什么好看的」 | `limit` 1–8、`fresh` |
| `weekly` | 「这周有什么必看」 | `number`（期数，不填最新）、`limit` |
| `search` | 「有没有 xx 的视频」 | `keyword`、`order`（play/pubdate/dm）、`limit`、`minPlay` |
| `video` | 有人发了链接 / BV 号 / 番剧 ep、ss | `link`、`comments`、`subtitle`、`danmaku` |
| `up` | 提到某个 UP 主 | `mid` 或 `name`、`limit` |

模型看到的工具名是 `mcp__bili__hot`、`mcp__bili__video` 这样。

`video` 的输出长这样（约 950 字节）：

```
《每 天 亿 遍 🔥 防 止 早 恋！》
UP：兔总裁s ｜ 播放 195.4万 ｜ 点赞 5.8万 ｜ 弹幕 868 ｜ 评论 1903 ｜ 1:13 ｜ 1天前
https://www.bilibili.com/video/BV1ZAWM61Evb
简介：……
字幕：没登录看不到 AI 字幕（只有标题、简介和热评）
弹幕抽样：0:01 谁又惹她高兴了? / 0:31 ？ / 0:46 越看越人机
热评：
 - 下盘蟹：冷白皮特效太多了吧！[笑哭]（112 赞）
```

## 装

**面板装**：扩展 → 市场 → 「刷 B 站」→ 安装 → 在权限页把 `ext_bili` 组调好。

**手放**（开发时更快）：

```
<数据目录>/extensions/bili/     # Windows: %USERPROFILE%\.dsh\dsh-roost\extensions\bili\
  plugin.json  server.mjs  lib/  README.md
```

放好之后重启 Roost（或让面板重载），工具会在下一轮出现。装完想确认通没通，直接问机器人「刷点B站」。

**注意**：`plugin.json` 里的 `command` 只是给宿主 launcher 读的，真正被 spawn 的是 `node ./server.mjs`，`cwd` 就是这个扩展目录。

## 可选：放一份 cookie.txt

匿名也能用（热门、搜索、视频信息、热评、弹幕都拿得到），但 **AI 字幕要登录**。

把浏览器里 B 站请求头里的 Cookie 整段贴进扩展目录的 `cookie.txt`（一行，`SESSDATA=...; bili_jct=...` 这样）：

```
<扩展目录>/cookie.txt
```

- 按文件 mtime 热读，改完不用重启；
- 只用来读，不做任何写操作（这个扩展没有写接口）；
- Cookie 等于账号密码：别提交到仓库、别贴进聊天记录、别放进截图；
- 不想要了直接删文件。

## 为什么没有「评论 / 弹幕 / 点赞 / 分区榜」

**写接口一个都没注册**，不是「注册了但提示模型别用」。原因：这个扩展在**群聊**里被调用，而它读的又是 B 站用户写的外部文本（标题、简介、评论、弹幕）——天生是提示注入的温床。把「能发东西的工具」从注册表里拿掉，注入写得再漂亮也无从调用；这比在提示词里写一百遍「不要发评论」可靠。要发评论请到框架插件侧做。

**分区排行榜拿掉了**：`ranking/v2?rid=N` 现在返回的是 2025-03-31 那一周的冻结快照（rid 4 / 36 / 188 实测同一天），拿它当「现在游戏区第一」会当场露馅。换成官方的「每周必看」（`weekly`），日期是真实的。

## 几个刻意的工程取舍

- **4 KB 预算**：宿主会在 4096 字节处硬截断工具输出（`src/ext-usage.js`），所以 `lib/format.mjs` 自己在 3600 字节处收口，字幕只给 420 字节、热评只给 4 条。中文一个字 3 字节，看着短其实刚好。
- **每次换一批**：`hot` 拉一份 20 条的池子，调用一次往后挪 6 条。同一批视频连推三次，谁都知道你没真刷。
- **请求节流 + 退避**：两次请求之间随机停 0.5–0.9 秒；命中 `412` / `-352` 就进程内停 10 分钟，不再撞墙。旁路接口（字幕 / 评论 / 弹幕 / 空间）不触发全局暂停 —— 一个可选字段拿不到，不该把整轮废掉。
- **搜索空结果重试一次**：B 站连着几个请求时会回 `code 0` + 空 `result`（软限流），等 800 ms 再问一次通常就有了。
- **弹幕均匀抽样**：从全片按步长取 8 条再按时间排序，比只看开头更能看出「这一片在聊什么」。
- **参数校验自己来**：MCP 客户端不会拒未知字段，模型把 `keyword` 写成 `keywrod` 会静默查空。这里直接报「不认识的参数：keywrod」。

## 调试

```bash
node server.mjs --list                    # 列出工具
node server.mjs --call hot '{"limit":3}'  # 直接调一个工具（不经宿主）
node test/smoke.mjs                       # 离线协议冒烟：握手 / 工具表 / 参数校验
node test/live.mjs                        # 真打 B 站接口（手动用，会发网络请求）
```

`--call` 的日志走 stderr，正文走 stdout —— 手动跑时两者都会显示，接进宿主时只有 stdout 是协议通道。

## 已知边界

- 不支持直播、付费 / DRM 内容、番剧的播放地址；
- 不抽帧、不下载视频（要图片得回框架插件侧，扩展拿不到发图能力，工具输出超 4 KB 还会把非文本块丢掉）；
- 弹幕走的是旧版 `list.so`，B 站哪天关掉它就只剩「无弹幕」；
- UP 主的「最近投稿」接口反爬很硬，偶尔只回资料、投稿为空（会如实写「拿不到」）；
- 未登录时字幕基本为空（B 站的 AI 字幕要登录）。
